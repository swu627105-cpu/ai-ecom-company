# 本地可复现参赛版本

应用仍是原AI电商公司三栏运营台，入口为 `http://localhost:5173/`。比赛展示位于公司频道、原审批中心与原任务列表。

## 启动

解压源码，进入platform目录，安装Node.js和Python3.11以上运行环境，执行：

```sh
bash scripts/start-local.sh
```

首次启动会安装前后端依赖，需要联网。评委使用自己的书生模型API Key在「模型配置」中设置。没有模型密钥时，「规则策略演练」可完整运行本地模拟流程。

如果依赖目录已存在但版本不一致，分别执行 `npm ci` 和 `apps/api/.venv/bin/python -m pip install -r apps/api/requirements.txt`。

## 点击验收

公司频道选择业务案例、编辑输入或导入JSON，启动书生或规则模式。风控通过后，在右侧审批中心追问、通过、驳回或退回修改。执行结果会改变本轮沙箱，原任务列表记录工具回执。

完成后录入模拟反馈，再创建下一轮。历史运行、方案版本、记录回放、证据导出和快照恢复均可从公司频道访问。会议、自定义议题、组织负责人、主管演示视角与操作审计保留原入口。

「评测」标签可重跑5个合成案例的规则基线或书生三组对照，结果包含失败记录与真实耗时。实时评测可能受网络和模型响应波动影响。

## 数据与边界

店铺授权和业务操作都是模拟。模型规划和风控是真实书生调用，规则模式会明确标注不调用模型。库存调拨、广告迁移和售后工单改变本地沙箱，不接外部店铺。

广告预算视为广告账户已预存额度，与可用调拨现金分开。ROI估算、模拟观察窗口和历史退款率分别展示，不声称真实收益或工单创建后退款率降低。

旧价格、采购、文案等通用提案仍为步骤演示，任务卡明确标记。主管视角是本地演示身份，源码没有生产登录或多租户权限系统。存储适用于本地单进程演示。

源码包排除API Key、settings.json、.env、用户运行状态、虚拟环境和node_modules。包含的案例、截图与执行记录为模拟经营材料。完整模型输出是结构化响应，不含模型隐式思维链。

## 比赛材料口径

已提供源码、测试、数据字典、操作说明、答辩讲述稿和实际评测证据。团队身份信息、授权商家脱敏数据和真实收益证明需由团队提供。PPT与正式录屏应使用实际界面和证据，不得把合成案例包装成真实商家成绩。
