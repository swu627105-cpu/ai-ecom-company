# 合成业务数据字典

JSON顶层为inventory、ads、service、finance，后端拒绝额外字段。可从公司频道下载数据模板。

| 字段 | 单位或含义 | 校验 |
| --- | --- | --- |
| inventory.sku | 商品名称/编号 | 1–80字 |
| inventory.stock | 店铺仓库存，件 | 非负整数 |
| inventory.daily_sales | 预测日销，件/天 | 正整数 |
| inventory.lead_days | 常规采购交期，天 | 1–90 |
| inventory.backup_stock | 备用仓可调拨库存，件 | 非负整数 |
| inventory.transfer_days | 备用仓交期，天 | 1–90 |
| inventory.transfer_unit_cost | 调拨单件费用，元 | 大于0 |
| ads.acquisition_budget | 拉新预算，元 | 非负整数 |
| ads.retention_budget | 复购预算，元 | 非负整数，总预算大于0 |
| ads.acquisition_roi | 拉新归因GMV/消耗 | 0–100 |
| ads.retention_roi | 复购归因GMV/消耗 | 0–100 |
| ads.breakeven_roi | 业务提供的保本线 | 大于0，不能由该比值推断净利润 |
| service.orders | 原观察窗口订单数 | 正整数 |
| service.refund_orders | 原窗口退款单数 | 不超过订单数 |
| service.damaged_orders | 原窗口破损退款单数 | 不超过退款单数 |
| service.previous_refund_rate | 上一窗口退款率，百分数 | 0–100 |
| service.tickets | 已建排查工单 | id唯一，含id、reason、status字符串 |
| finance.available_cash | 可用于模拟调拨的现金，元 | 非负 |
| finance.spent | 累计模拟调拨费用，元 | 非负，包含上一轮带入值 |

库存覆盖=stock/daily_sales。预算加权ROI=(拉新预算×拉新ROI+复购预算×复购ROI)/广告总预算。该比值为固定ROI假设下的估算。历史退款率=refund_orders/orders×100%，创建或解决工单均不修改该历史样本。

反馈只对已完成运行录入一次。发货件数扣减当前库存，下一轮预测日销更新需求，广告消耗与归因GMV更新对应ROI，零消耗表示未观察。每条工单可转为已解决，但不自动退款。原执行结果单独保留在execution_result。下一轮复制反馈后的完整快照，不重复创建已有工单。

数据来源全部为合成，尚无真实商家授权样本。

本演示假定广告预算已经存入广告账户，与可用调拨现金分开。反馈中的广告消耗是观察窗口输入，不会再次从调拨现金扣款。模型接收工单数量摘要，完整工单列表保留在原始快照中，待人工联系也属于已经创建的工单。
